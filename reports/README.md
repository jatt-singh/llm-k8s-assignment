# Security reports

Generated by `scripts/ci.sh check` (stages `scan` and `sbom`). Regenerate with `make check`.

| Path | Contents | Tool |
|---|---|---|
| `sbom/<image>.spdx.json` | SPDX 2.3 JSON SBOM per image | Syft |
| `scans/<image>.txt` / `.json` | Full vulnerability report, all severities | Trivy (`trivy image --scanners vuln`) |
| `scans/k8s-manifests-misconfig.txt` | Misconfiguration scan of the rendered Helm chart (gated: HIGH/CRITICAL fail) | Trivy (`trivy config`) |
| `scans/terraform-misconfig.txt` | Misconfiguration scan of the Terraform (report only) | Trivy (`trivy config`) |
| `tool-versions.txt` | Tool versions, vulnerability DB version, image tag and image IDs | - |

**Gate policy:** the build fails if any image contains a vulnerability with severity **≥ CRITICAL** that has a fixed version available (`--ignore-unfixed`). Change the threshold with `SEVERITY_THRESHOLD=HIGH make check`. Accepted exceptions go in `/.trivyignore` with a reason and a review date (currently none).

See `SUMMARY.md` for the latest results and how residual findings are handled.
